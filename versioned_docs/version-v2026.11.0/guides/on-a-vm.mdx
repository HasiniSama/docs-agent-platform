# Run Agent Manager on a VM with Docker

Agent Manager 2026.11.0 is a short-term support (STS) release, available only with a WSO2 subscription or evaluation. The VM installer is not published for it.

To install it, follow the [k3d guide](./on-k3d.mdx) or the [On Your Environment](./on-your-environment.mdx) guide, with the values in [Install with a WSO2 Subscription](./install-with-a-wso2-subscription.mdx).
