# Quick Start Guide

Agent Manager 2026.11.0 is a short-term support (STS) release, available only with a WSO2 subscription or evaluation. The Quick Start dev container is not published for it.

To install it with a single command, use the **Run One Command** tab of the [k3d guide](../guides/on-k3d.mdx#install). See [Install with a WSO2 Subscription](../guides/install-with-a-wso2-subscription.mdx) for your registry credentials and project.
